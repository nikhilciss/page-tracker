Connect your website

  1. Sign up with your company website. Its root URL must return HTTP 200; redirects are not followed.
  2. Open Profile & integration and copy the script tag.
  3. Add the tag to any rendered page or shared layout you want recorded. No API key, host .env changes or token endpoint is needed.

For local development, configure LOCAL_VERIFICATION_ORIGINS on the tracker service. The website check confirms availability, not ownership.
